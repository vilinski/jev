Reading the results

Public benchmark. On a 330-item sample of jev-bench, Celeris is clearly the most accurate (84%, 95% CI 80%–88%) and best calibrated (Brier 0.220). Clef (78%) and Jev (76%) follow, then OpenAI Decisions (72%); the DIY chat adapter is far behind because it cannot handle questions with more than 26 options (five datasets). The 95% intervals are about ±4.5 points wide, so Celeris leads OpenAI Decisions clearly, while Clef and Jev are statistically tied.

Speed. Jev (467 ms) and OpenAI Decisions (414 ms) have the lowest median on my own set, Celeris is steady at 535 ms, Clef is slower with a long tail (p95 1572 ms, slowest call 7.5 s). Celeris advertises 67 ms from AWS us-east-1; from here, through the CLI with a new TLS handshake per call, every number is dominated by the network path. The first call of each run is left out as a cold start.

My own 60-item set is easy: all five models are within a few points of each other (93% to 96%), and one answer is worth almost two points. OpenAI Decisions has the best calibration here (Brier 0.0023 yes/no, 0.0026 routing), Jev is the only model that answers every vague input with “can’t tell” (100%), and the DIY chat adapter is nearly as confident when wrong (0.94) as when right (0.97). On the harder public data the ranking changes, which is the reason to trust the larger set more.

Cost. All four dedicated decision APIs cost between $0.0058 and $0.0179 per 1,000 single-question decisions on my short inputs, and $0.0144 to $0.0417 on the longer public-benchmark inputs, so a million decisions costs roughly $6 to $42. OpenAI Decisions is priced at $0.10 per million input tokens with no output charge; the DIY chat route costs about 7x Celeris on short inputs. Cost is a minor factor at small scale; accuracy and calibration matter more. Tokens are counted by each vendor’s own tokenizer.

Caveats. The public sample is 15 items per dataset, one run, so differences under about 5 points are inside the error margin. My own set is synthetic, small and easy, with 3 repeats. Latency comes from the jev CLI on one machine. Severity labels on my set are my own judgement. Scoring on jev-bench counts a failed or refused request as a uniform answer. jev-bench is published by a third party and has a mixed licence; I used only a small sample of its test splits. The OpenAI Decisions API is in public beta. No sponsorship or affiliation with any of these vendors.
