Reading the results

Public benchmark. On a 1100-item sample of jev-bench, Celeris is the most accurate (81%, 95% CI 79%–84%) with the best Brier score (0.265). Then Clef (77%, 4 points behind Celeris, intervals overlap), Jev (72%, 4 points behind Clef, intervals overlap), OpenAI Decisions (68%, 4 points behind Jev, intervals overlap). The DIY chat adapter (55%) is far behind because it cannot handle questions with more than 26 options (five datasets). The 95% intervals are about ±2.6 points wide.

Speed. Jev (437 ms) and OpenAI Decisions (402 ms) have the lowest median on my own set, Celeris is steady at 528 ms, Clef is slower with a long tail (p95 2720 ms, slowest call 6.9 s). Celeris advertises 67 ms from AWS us-east-1; from here, through the CLI with a new TLS handshake per call, every number is dominated by the network path. The first call of each run is left out as a cold start.

My own 60-item set is easy: all five models are within a few points of each other (93% to 96%), and one answer is worth almost two points. OpenAI Decisions has the lowest routing Brier (0.0026) and a yes/no Brier (0.0023) that only the DIY adapter (0.0018) beats, Jev is the only model that answers every vague input with “can’t tell” (100%), and the DIY chat adapter is nearly as confident when wrong (0.94) as when right (0.97). On the harder public data the ranking changes, which is the reason to trust the larger set more.

Cost. All four dedicated decision APIs cost between $0.0058 and $0.0179 per 1,000 single-question decisions on my short inputs, and $0.0145 to $0.0421 on the longer public-benchmark inputs, so a million decisions costs roughly $6 to $42. OpenAI Decisions is priced at $0.10 per million input tokens with no output charge; the DIY chat route costs about 7x Celeris on short inputs. Cost is a minor factor at small scale; accuracy and calibration matter more. Tokens are counted by each vendor’s own tokenizer.

Caveats. The public sample is 50 items per dataset, one run, so differences under about 3 points are inside the error margin. My own set is synthetic, small and easy, with 3 repeats. Latency comes from the jev CLI on one machine. Severity labels on my set are my own judgement. Scoring on jev-bench counts a failed or refused request as a uniform answer. jev-bench is published by a third party and has a mixed licence; I used only a small sample of its test splits. The OpenAI Decisions API is in public beta. No sponsorship or affiliation with any of these vendors.
